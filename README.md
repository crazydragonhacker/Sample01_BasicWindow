# Java Swing GUI Application

A simple beginner-level **Java Swing GUI application** that demonstrates how to create and customize a desktop window using Java's Swing and AWT libraries.

## Features

* Creates a GUI window using `JFrame`
* Uses a custom `JPanel`
* Applies `BorderLayout`
* Sets a custom background color
* Sets window size and title
* Centers the window on the screen
* Adds a custom window icon
* Prevents window resizing
* Handles window closing using `JFrame.EXIT_ON_CLOSE`

## Technologies Used

* Java
* Java Swing
* Java AWT

## Main Classes

* `MainClass` – Contains the `main()` method and starts the application.
* `MainFrame` – Creates and configures the main application window.
* `MainPanel` – Represents the panel displayed inside the frame.

## Purpose

This project was created to learn the fundamentals of **GUI development in Java** and understand how `JFrame`, `JPanel`, layouts, colors, and other Swing/AWT components work together.
